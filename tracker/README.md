# 刊行後トラッカー

本書（2026年2月12日刊行）の章立てをスナップショットとして使い、刊行後のAIをめぐる動きを章ごとに追いかけるための作業場。公開サイトにはまだ出していない。

## 流れ

1. **収集**（Claude）：章ごとに、刊行後の出来事・研究・政策・本を調べて `candidates.json` に候補として登録する。
2. **トピック化**（Claude）：候補を章ごとのトピックに束ねて `topics.json` に登録する。トピックは「その章に節を足す価値があるか」を判断する単位。
3. **レビュー**（共著者）：レビューページで、トピックごとに判定（節を追加／コラム・追記／見送り）、トーン、コメントを記入する。章ごと・全体への指示も書ける。
4. **反映**（Claude）：判定と指示を読んで、次の収集や本文の下書きに反映する。公開サイトへの組み込み方は、判定がそろってから決める。

## レビューページ

- URL：https://claude.ai/artifact/EXa6PUnZtr7MmWzWnaBUQf （非公開。共有はclaude.aiの共有メニューから）
- 記入者は画面上部で「谷口／鈴木／丸山」から選ぶ。記入は人ごとに別々に保存され、互いの記入も表示される。
- データ（候補・トピック・判定・指示）はページのデータベースに保存される。`candidates.json` と `topics.json` はその控え。

## ファイル

| ファイル | 内容 |
|---|---|
| `chapters.json` | `index.html` の DATA から抽出した章・節構成（刊行時点） |
| `candidates.json` | 候補（出来事・研究・政策・本）。1件ごとに日付、要約、本書との関係、出典、確度 |
| `topics.json` | 章ごとのトピック。節の案、Claudeの見立て、根拠となる候補のid |
| `review.html` | レビューページのソース |

## 分類と用語

- 候補の種類：技術／インシデント／政策・制度／議論・研究／本
- 本書との関係：補強／更新／揺さぶり／拡張
- トーン：事実の補遺／問いの更新／論争の整理／著者の見解
